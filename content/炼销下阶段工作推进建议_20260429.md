# 炼销下阶段工作推进建议

更新日期：2026-04-29

## 一、总体判断

炼销下个阶段不建议继续平均铺开，而应从“需求与方案阶段”切换到“联调、验收、闭环阶段”。

当前最核心的推进目标是打通主业务链路：

`订单下发 -> 自动/半自动建单 -> 运输执行 -> 计量回传 -> 费用结算 -> 风险预警`

因此，下阶段工作应优先围绕运输中心、订单中心、费用结算和风险闭环展开，控制并行面，优先做成可联调、可验收、可追溯的业务闭环。

## 三、建议推进节奏

1. 5月聚焦主链路，优先打通订单下发、自动建单、运输执行、计量回传、异常补处理。
2. 6月在主链路稳定后，补齐费用结算、报表增强、风险闭环。
3. 远期方向先做范围收敛和预研，不抢占主研发资源。

## 四、下阶段核心验收目标

1. 水路自提和短驳场景可以端到端跑通。
2. 异常单据能够补建、修正、重试，并形成留痕。
3. 费用和报表能够基于真实业务结果对账，不停留在展示层。

## 五、重点关注风险

1. 最大风险不是开发量，而是跨中心口径不统一。
2. 最大依赖不是页面功能，而是订单中心、电子提货系统、轨迹能力三方联动。
3. 最大管理风险是并行开线过多，导致运输中心主链路迟迟不闭环。

## 六、建议的管理动作

1. 将“运输中心联调闭环”单独设为专项，由产品、研发、测试、业务共同跟踪。
2. 每周按场景而非按模块汇报进展，避免看似都在推进、实则链路未打通。
3. 对 P0、P1 项逐项建立联调清单、异常清单、责任人和计划完成时间。
4. 对远期方向只保留预研和范围澄清，不提前大规模投入研发。
